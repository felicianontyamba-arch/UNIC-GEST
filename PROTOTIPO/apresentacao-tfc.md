# Apresentação do TFC - UNIC GEST

## 1. Tema
Sistema de gestão académica para estudantes universitários, com foco em organização de tarefas, acompanhamento de desempenho e melhoria da produtividade académica.

## 2. Problema identificados
- Os estudantes costumam perder o controlo de prazos e tarefas importantes.
- Há dispersão de informação entre calendário, estudos e entregas.
- Falta uma plataforma centralizada para gerir disciplina, progresso e alertas.

## 3. Objetivo da solução
Criar uma aplicação web intuitiva e funcional que ajude o estudante a:
- gerir tarefas por disciplina;
- acompanhar o progresso académico;
- visualizar prazos e prioridades;
- receber alertas e manter organização pessoal.

## 4. Funcionalidades principais
- Login para estudante e administrador
- Dashboard com visão geral de tarefas
- Gestão de disciplinas
- Criação, edição e eliminação de tarefas
- Organização por prioridade e estado
- Progresso académico e indicadores
- Notificações e alertas
- Exportação de dados em CSV, Excel e PDF
- Design responsivo para desktop e mobile

## 5. Arquitetura do projeto
- Frontend: HTML, CSS e JavaScript puro
- Backend: Node.js + Express
- Dados: MySQL + estrutura de apoio em SQL
- Segurança: autenticação com JWT e senha em hash
- Publicação local: servidor em localhost:5000

## 6. Fluxo de demonstração
1. Aceder à landing page
2. Fazer login como estudante ou administrador
3. Entrar no dashboard
4. Ver tarefas, prazos e indicadores
5. Navegar para disciplinas e progresso
6. Ver exportações e administração de dados

## 7. Pontos fortes da solução
- Interface mais clara e profissional
- Organização visual por módulos
- Funcionalidade útil no dia a dia académico
- Estrutura pronta para evolução e integração real com base de dados
- Boa relação entre usabilidade e funcionalidade

## 8. Limitações honestas
- O sistema ainda funciona em grande parte com dados de demonstração
- A integração completa com base de dados real depende de ambiente e testes adicionais
- Há espaço para reforço de autenticação, validações e UX avançada

## 9. Roteiro de defesa (3 minutos)
### Introdução
"Este projeto nasceu da necessidade de ajudar estudantes a organizar melhor a vida académica e evitar esquecimentos em trabalhos e prazos."

### Problema
"O grande problema é a falta de centralização e organização, especialmente quando há muitas disciplinas e tarefas em simultâneo."

### Solução
"Desenvolvemos um sistema web chamado UNIC GEST que reúne dashboard, tarefas, disciplinas, notificações e acompanhamento de desempenho em uma só plataforma."

### Tecnologias
"Usamos HTML, CSS e JavaScript no frontend, e Node.js com Express no backend, com foco em uma arquitetura simples, funcional e fácil de expandir."

### Demonstração
"Nesta aplicação, o utilizador consegue entrar, ver o painel principal, gerir tarefas e acompanhar o seu progresso académico."

## 10. Mensagem final para apresentação
O projeto UNIC GEST demonstra uma solução prática e relevante para a gestão acadêmica, com foco em organização, produtividade e acompanhamento de desempenho. Apesar de ser um protótipo funcional, ele evidencia uma boa visão de produto e um caminho realista para desenvolvimento futuro.
